# Nail Gallery — one-page website demo

Unsolicited demo concept for **Nail Gallery**, a nail salon at
304 W Evergreen Ave, Ste 104, Palmer, AK 99645 · (907) 745-1311.

Built as a free preview by **Digital Consulting Studios**, a Mat-Su Valley web studio.
**Not commissioned by, affiliated with, or endorsed by the business.** The business has
not been contacted about this preview.

- Single self-contained `index.html` — inline CSS + JS, no build step, no external assets
  beyond a Google Fonts stylesheet and an OpenStreetMap embed.
- `noindex,nofollow` is set deliberately and must stay until the page is commissioned.
- Photographs, opening hours, the full service menu and all pricing are **visible
  placeholders**. Nothing on the page is invented. See `PLACEHOLDERS.md`.
- Aggregate ratings appear only with their source named.

Live preview: GitHub Pages, `main` branch, root.
